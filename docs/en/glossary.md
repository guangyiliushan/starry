# Glossary

| Term | Definition |
|---|---|
| ARC | Automatic reference counting. A class instance is released when its last strong reference disappears. |
| Class | A reference-counted aggregate with fields, methods, and optional inheritance. |
| Diagnostic | A stable, positioned report produced when a source file is rejected. |
| Manifest | A `starry.toml` file that names a package and declares exact path dependencies. |
| Module path | Compiler metadata derived from a package name and source-file directory. |
| Nullable type | A type whose value is either present or `null`. |
| Package | A source root identified by `starry.toml`. |
| Pattern | A test and optional binding form used by `is` and `when`. |
| Trait | A named set of method requirements with at least one implementation for a concrete type. |
| Weak reference | A nullable class reference that does not keep its target alive. |
