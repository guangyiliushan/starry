# 术语表

| 术语 | 定义 |
|---|---|
| ARC | 自动引用计数。最后一个强引用消失时，类实例被释放。 |
| Class | 具有字段、方法和可选继承的引用计数聚合。 |
| 诊断 | 源文件被拒绝时产生的带位置的稳定报告。 |
| Manifest | 标识包并声明精确路径依赖的 `starry.toml` 文件。 |
| 模块路径 | 由包名和源文件目录推导出的编译器元数据。 |
| 可空类型 | 值要么存在，要么为 `null` 的类型。 |
| 包 | 由 `starry.toml` 标识的源码根。 |
| 模式 | `is` 和 `when` 使用的测试与可选绑定形式。 |
| Trait | 一组命名方法要求，并且对某个具体类型至少有一个实现。 |
| 弱引用 | 不让目标保持存活的可空类引用。 |
