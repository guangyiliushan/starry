# Starry

Starry is a small language implemented by a textbook compiler pipeline.

Choose an entry point:

- Install the toolchain: [Install](start/install.md)
- Write and run a first program: [Tutorial](start/tutorial.md)
- Check syntax before writing code: grammar and lexicon under `Spec`
- Inspect a rejected program: diagnostics under `Reference`

The documentation describes the current language only. It does not maintain release history.
